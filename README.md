# Desenvolvimento de uma Aplicação Web para Geração e Envio de Orçamentos Personalizados para uma Marcenaria

## 📌 Sobre o Projeto
Projeto Integrador II desenvolvido para o curso de Engenharia de Computação da UNIVESP. O objetivo é criar uma aplicação web para digitalizar, organizar e agilizar a elaboração e envio de orçamentos personalizados de uma pequena marcenaria.
